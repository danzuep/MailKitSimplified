# Quick start

## Run tests

From VS Code or Visual Studio, use Ctrl+` to open a terminal then run the following:

```sh
dotnet run --file ./tests/e2e-tests.cs
```

For MailKitSimplified.Sender.Tests\MailKitSimplified.Sender.Tests.csproj

```sh
dotnet run --project ./tests/MailKitSimplified.Sender.Tests/MailKitSimplified.Sender.Tests.csproj
```

For MailKitSimplified.Receiver.Tests\MailKitSimplified.Receiver.Tests.csproj

```sh
dotnet run --project ./tests/MailKitSimplified.Receiver.Tests/MailKitSimplified.Receiver.Tests.csproj
```
